Profile — Required vs Inferred Fields

What the system needs before it can apply. Green = must have. Grey = AI figures it out.

REQUIRED — AI blocks until these exist
Identity
Full name · Email · Phone · Location (city + country)
Work History (min 1 job)
Company · Job title · Start & end dates · What you did (bullets or description)
Skills
At least 3 — languages, frameworks, tools (e.g. Flutter, Django, PostgreSQL)
Education
Degree · Institution · Graduation year (ATS forms almost always ask)
INFERRED — AI calculates from the required data
Salary Range
Derived from seniority level + role location + company size signals
Seniority Level
Junior / Mid / Senior — derived from years of experience across work history
Job Sub-Categories
Flutter → Mobile Dev. Django → Backend. React → Frontend. AI infers from skills.
Professional Summary
Generated per application — tailored to match each JD's language and keywords
Cover Letter / Form Answers
Generated per application from profile + JD context
OPTIONAL — improves quality if provided
GitHub URL
Many dev roles ask for it
LinkedIn URL
Common ATS field
Portfolio / Website
Frontend, design, full-stack roles
Certifications
AWS, GCP, PMP, etc.
Languages Spoken
Relevant for multilingual roles
Work Preferences
Remote / hybrid / onsite, willing to relocate
