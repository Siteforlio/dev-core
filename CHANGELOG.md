## [0.1.0] — 2026-06-12

### Added
- Interview Prep module: AI interview simulator with configurable persona, multi-round pipeline (behavioral, technical, coding), real-time feedback, post-session debrief
- Job Hunter module: automated scraping from LinkedIn, ATS portals, Kenya job boards, startup boards; campaign management; AI resume tailoring; cross-campaign duplicate detection; manual apply flow
- Auth system: JWT access + refresh tokens, PIN unlock, persistent sessions
- Docker Compose setup: PostgreSQL, Neo4j, Redis, Celery worker, nginx load balancer
- Electron desktop shell with IPC bridge
